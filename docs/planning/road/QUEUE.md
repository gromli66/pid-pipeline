# Очередь исполнения — дорога 2026-08-17

Порядок выведен заново из мастер-плана (167 пунктов извлечены и сверены с кодом 2026-08-17,
см. `PLAN_AUDIT.md`) по четырём правилам самого плана: (1) сначала опора — гейты и стенды,
без них «без поломки» недоказуемо; (2) затем кровь — падения и порча данных; (3) сведение
дублей — непосредственно перед фронтом, который их правит; (4) перемещение файлов — последним.

**Правило волн:** волна N начинается, когда её замки (⛔) закрыты. Внутри волны порядок
сверху вниз; пункты без стрелок можно брать в любом порядке после жёстких. Один пункт =
одна сессия исполнителя. Класс/гейт — по таблице в `PROTOCOL.md`.

Обозначения: ⚠ — правит бой или массовая правка, после неё обязателен чат-ревизор;
⛔ — замок (не начинать, пока не закрыт); ✅ — сделано до создания дороги, проверить и закрыть
на доске; [класс] — класс изменения из `PROTOCOL.md`.

**Колонка «модель»** — какой моделью запускать чат-исполнитель пункта:
- **Opus 5** — дефолт для всех пунктов. Запасной вариант при лимитах — Opus 4.8
  (допустим на [док]/[снос]/[infra]; на ⚠ и [сма]/[гео] — только Opus 5).
- **Fable 5** — 13 архитектурно тяжёлых пунктов (кэш моделей, transitions, базовая
  задача+диспетчеризация, посадка Г5б, дедуп рёбер, запись концов, разбор AGE и god-функций,
  seat-rect, graph_to_fxml): там решения, а не механика.
- Чат-ревизор — всегда Fable 5 (проверяющий не слабее проверяемого); диспетчер — можно Opus 4.8.
- Режим: пункты с ⚠ начинать в **план-режиме** (план правки → ваше утверждение → код);
  полный auto-accept разрешений не давать никому.
- **Размышления** — рекомендованный режим стоит в колонке «модель» у каждого пункта:
  `обычн.` / `расшир.` (дописать «думай тщательно») / `ultrathink`. Включается Tab'ом
  в Claude Code или словом в конце промпта. Ревизор — всегда ultrathink, диспетчер — обычный.
  Максимум всем подряд НЕ включать: на механике длинные размышления провоцируют
  «улучшить заодно» (красный флаг №6).
