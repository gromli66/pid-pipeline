# ADR-003: 6-канальный вход SAM2 (несмотря на паритет с RGB-only)

**Статус:** Принято (6ch для production, несмотря на паритет метрик)  
**Дата:** 2025-12  
**Контекст:** Выбор входных каналов для SAM2 fine-tune

---

## Контекст

SAM2 base принимает 3ch RGB. Для P&ID задачи доступны дополнительные каналы: rough mask (ch3), pipe mask (ch4), neighboring nodes (ch5). Вопрос: добавляют ли auxiliary каналы точности?

## Эксперимент

Обучены модели на идентичном датасете (915 samples) с LoRA r=8:

| Конфигурация | Каналы | Результат |
|-------------|--------|-----------|
| RGB-only | 0–2 (RGB) | Baseline |
| RGB + rough mask | 0–3 | В пределах 1.3% от baseline |
| RGB + pipe + nodes | 0–2, 4–5 | В пределах 1.3% от baseline |
| Full 6ch | 0–5 (все) | В пределах 1.3% от baseline |

Все варианты с auxiliary каналами — в пределах шума 1.3% от RGB-only.

## Решение

**6ch для production**, несмотря на паритет метрик.

## Обоснование

1. **Метрики на текущем датасете.** Все конфигурации показали одинаковый результат. Bottleneck — количество данных (915), а не информация на входе.
2. **Edge cases.** На сложных кейсах (перекрывающиеся символы, символы рядом с трубами) дополнительные каналы теоретически помогают модели. При росте датасета эффект может стать статистически значимым.
3. **Стоимость.** 6ch: +~5% inference time (расширение patch_embed), zero training cost increase (LoRA не зависит от input channels). Дополнительные каналы уже генерируются pipeline (pipe_mask, COCO annotations) — нет overhead в подготовке данных.
4. **Reversibility.** Patch_embed для ch 3–5 инициализируется нулями — если каналы пустые, модель ведёт себя как RGB-only.

## Последствия

- Patch_embed расширен до 6ch: ch 0–2 копируют pretrained RGB, ch 3–5 = zeros.
- При inference: если pipe_mask недоступен — ch4 = zeros (graceful degradation).
- При росте датасета до ~3000+ стоит повторить A/B эксперимент.
