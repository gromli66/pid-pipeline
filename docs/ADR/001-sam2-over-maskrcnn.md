# ADR-001: SAM2 вместо Mask R-CNN / Detectron2

**Статус:** Принято  
**Дата:** 2025-12  
**Контекст:** Выбор модели для извлечения контуров символов оборудования на P&ID схемах

---

## Контекст

Для pipeline требуется модель, которая по rough bbox (от YOLO) выдаёт точный полигон контура символа оборудования. Символы — чёрно-белая графика с чёткими линиями, 36+ классов, от простых (заглушка) до сложных (теплообменник с внутренней структурой).

## Рассмотренные альтернативы

**Mask R-CNN / Detectron2.** Instance segmentation end-to-end: detects + segments в одном проходе. Требует обучения с полигонной разметкой для каждого класса. Плюсы: зрелый стек, хорошая документация. Минусы: нужно много полигонной разметки (сотни примеров на класс), качество масок ограничено 28×28 output resolution, требуется отдельная модель.

**SAM2 + LoRA.** Foundation model для сегментации с prompt (point/bbox). Fine-tune через LoRA — малое количество trainable параметров. Плюсы: работает из bbox prompt (не нужен отдельный детектор-сегментатор), высокое разрешение масок (1024×1024), малый объём обучающих данных для fine-tune. Минусы: дополнительный вес base модели (~150 MB), зависимость от HuggingFace/Meta checkpoint.

## Решение

SAM2 Hiera Small + LoRA r=8.

## Обоснование

1. **Данные.** На момент решения было ~200 полигонных аннотаций — недостаточно для Mask R-CNN, но достаточно для LoRA fine-tune SAM2.
2. **Разрешение.** SAM2 работает на 1024×1024 — контуры значительно точнее 28×28 масок Mask R-CNN.
3. **Архитектура.** YOLO уже детектирует bbox. SAM2 принимает bbox как prompt — естественная интеграция без дублирования detection stage.
4. **Скорость разработки.** LoRA fine-tune SAM2 — дни, обучение Mask R-CNN с нуля — недели (разметка + обучение + тюнинг).

## Последствия

- Base checkpoint (~150 MB) скачивается заранее (`scripts/download_sam2_base.py`), runtime загрузки заблокированы.
- SAM2 inference дороже по GPU RAM (~4 GB) — выделен отдельный worker/queue.
- Smart snap нужен для регуляризации полигонов (SAM2 выдаёт pixel-level маску, не инженерные полигоны).
