# P&ID — десктоп-клиент для Astra Linux — установка

Автономная сборка клиента P&ID для **Astra Linux 1.7 / 1.8 (x86_64)** и
Debian-совместимых систем с графическим рабочим столом. Внутри уже всё:
Python, Qt, WebEngine и зависимости — **ставить Python, venv или библиотеки
не нужно**. Подходит для закрытого контура.

Клиент тонкий: подключается к серверу P&ID по сети (HTTP). Сервер и модели —
отдельно (см. `DEPLOY_README.md`).

Собрано в образе `manylinux_2_28` (glibc 2.28) → совместимо и с Astra **1.7**, и с **1.8**.

---

## Установка и запуск

1. Распаковать архив (имя с датой-версией):
   ```bash
   tar -xzf PID-Client_astra_2026-07-02.tar.gz
   cd PID-Client
   ```
2. Вписать адрес сервера в `client.cfg` (строка `PID_API_URL`):
   ```bash
   nano client.cfg
   # PID_API_URL=http://147.45.246.93:8000   ← пример, подставьте свой сервер
   ```
3. Запустить:
   ```bash
   ./run_standalone.sh
   ```
   (или напрямую `./PID_Pipeline`)

Признак успеха: открылось окно, слева подгрузился список диаграмм, внизу нет
«API недоступен». В заголовке окна видна версия (дата сборки).

---

## Сменить адрес сервера позже

Отредактируйте `PID_API_URL` в `client.cfg` рядом с бинарником и перезапустите клиент.

## Что внутри архива

```
PID-Client/
  PID_Pipeline        ← исполняемый файл
  run_standalone.sh   ← запуск
  client.cfg          ← адрес сервера + настройки отрисовки
  version.txt         ← версия (дата сборки)
  configs/            ← конфиги проектов
  README.txt          ← короткая памятка
  _internal/          ← библиотеки (не трогать)
```

## Примечания

- Отрисовка по умолчанию — программный GL (`PID_GL_BACKEND=software` в `client.cfg`):
  универсально для виртуалок и Astra без видеоускорения. При нормальном GPU можно
  сменить на `gles`.
- Вкладка **CVAT** работает, только если сервер доступен клиенту по сети, а в `.env`
  сервера `CVAT_BROWSER_URL` указывает на доступный клиенту хост.
- На «голой» системе без десктопа могут отсутствовать базовые Qt-библиотеки —
  доустановите (нужен root):
  ```bash
  sudo apt-get install -y libgl1 libegl1 libxkbcommon0 libfontconfig1 \
      libdbus-1-3 libnss3 libxcomposite1 libxdamage1 libxrandr2 libxtst6 libasound2
  ```
- Архитектура: только x86_64.
